Wat deze proef wel/niet doet

Hij gebruikt Spotify Web API playback-control op het actieve Spotify/Spotify Connect-apparaat. Hij verandert geen W39-data, beoordelingen, Explorer-route of playlists. Na deze proef testen we apart of “één track = daarna stil” betrouwbaar afdwingbaar is.
