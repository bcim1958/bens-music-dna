# Ben's Music DNA — Design System

## Principle
**The logo says what Music DNA is. The cinematic language says how Music DNA feels.**

The app may be beautiful and rich, but beauty must serve the music.

## Brand mark
Semantic core: double DNA helix + sound waveform.
Chosen 2026-09-03 direction: **C — Living DNA**.

### Living DNA refinement target
- black/dark base;
- emerald/electric green living mark;
- helix and waveform feel like one movement rather than two stacked symbols;
- slightly clearer helix at true iPhone icon size;
- waveform expressive but not visually noisy;
- subtle central light source, not a decorative star;
- no tiny text inside the app icon;
- optimized for recognition among normal iPhone apps.

## Cinematic UI language
- dark, calm, immersive background;
- light in darkness rather than glossy 3D decoration;
- selective gold warmth for key music/emotion accents;
- blue for calm positive resonance;
- violet for return/Second Chance/action;
- red/orange for a signal that fades/stops, not punishment;
- restrained motion; no carnival effects.

## Four reaction objects
These are bespoke visual objects, not stock emoji/icons.

### RAAK
Golden light impact/spark. Moment of being struck by music.
Micro-animation idea: brief expansion/light burst.

### GOED
Blue musical resonance/wave. Calm positive fit.
Micro-animation idea: gentle pulse/breath.

### NOG EENS
Violet returning film/light ribbon. A story/encounter not yet finished.
This object should become a reusable visual motif for Second Chance elsewhere in the app.
Micro-animation idea: one restrained returning loop.

### NEE
Red/orange waveform or light that dies into black.
No thumbs-down, cross or aggressive rejection.
Micro-animation idea: signal softly fades.

All four reactions are visually equal in size/status so the UI does not bias Ben's judgement.

## Choice screen hierarchy
1. Music/artwork/artist/track.
2. Playback/progress including elapsed + remaining time.
3. Prompt: `Wat deed dit nummer met je?`
4. Four cinematic reaction objects.
5. Explicit Previous Discovery / Next Discovery navigation.
6. Supporting explanations only where needed; avoid repeated instructional clutter in mature daily use.

## Action indicator
Preferred accent: violet, clearly separate from emerald brand mark.
Badge appears only when action is required. Counter represents actionable items, not general notifications.

## Motion
Target micro-animations roughly 300–500 ms, subtle and purposeful. A selection should feel acknowledged without delaying the daily flow.

## Visual reference policy
Concept images created in chat are design references, not source-of-truth assets until stored/exported into the repository. Important accepted visuals should be archived as project assets with a short README describing what is accepted from each image.
