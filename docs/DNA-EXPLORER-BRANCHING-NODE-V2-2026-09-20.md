# DNA Explorer — branching-node proof v2 — 2026-09-20

## Product decision
Ghost is no longer modeled as a single linear route. It is the first **Explorer node**.

Immediate structured door families:
1. Music
2. People
3. Relationships
4. Musical world
5. Stories
6. Time & place

A seventh action sits above the categories:
**✦ Kies een interessante afslag voor mij**

## Rule
Large choice is welcome when it is structured. The user should see many possible directions quickly without facing a flat wall of links.

Every object can become another node: artist, track, album, person, genre/style, story/source, place, year/era.

## Surprise action
The surprise action chooses among rich doors at the current node. It is distinct from homepage “Verras me!”:
- homepage surprise chooses a starting point;
- Explorer surprise chooses the next turn.

## ABBA grounding

This makes ABBA a strong example of an unexpected but sourceable Explorer door.
